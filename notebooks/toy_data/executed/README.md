# Executed Notebook Snapshots

These notebooks contain the inline figures and tables used for reading the
pre-class notes without running training first. They are generated from the
clean source notebooks one directory above by `scripts/run_toy_notes.py` and
should not be edited directly.

The six lightweight snapshots are executed together with fixed seeds. The
CIFAR-10 image experiment is executed separately because it requires locked
external assets. The source notebooks remain the canonical code; these copies
are the viewable publication artifacts.

The published snapshots were executed on an NVIDIA RTX A6000. The execution
reports, numerical checks, and figure-count checks must pass before these files
are updated.
